# 3D-printable model rocket

A 270 mm model rocket for a standard 18 mm hobby motor, with a bilingual (English / 繁體中文) picture guide for printing, packing and launching it.

**Live guide:** https://hw0006.github.io/rocket-guide/

## Files

| File | Use |
|---|---|
| `files/rocket_airframe.stl` | Print: airframe, fins down, no supports |
| `files/rocket_nosecone.stl` | Print: nose cone, point up |
| `files/rocket_assembly.step` | Open in CAD |
| `files/rocket_airframe.step`, `files/rocket_nosecone.step` | Single parts for CAD |
| `files/rocket.py` | Parametric source (CadQuery); change sizes at the top and re-run |
| `files/rocket_files.zip` | Everything above |

## Status

Not yet printed or flown. Stability figures are estimates (margin about 1.35 body diameters with 10 g of nose weight and an assumed 24 g motor). Do a real balance check and fit a recovery system before any launch.
